# Cakelmius Bakery Website

A responsive bakery website built with HTML, CSS, and JavaScript. This was a practice project made during the **C-Data & CIT Front-end Web Development training**, based on an open-source template.

## About

This project started as a way to practice front-end fundamentals (HTML structure, CSS styling, basic JS) by working with an existing open-source template rather than building from a blank page — a common and useful way to learn as a beginner.

The base template is [Barbershop-website](https://github.com/bhavyavj/Barbershop-website) by [bhavyavj](https://github.com/bhavyavj). From it, this project:

- Replaced all the content/copy with new bakery-themed text
- Replaced the images with bakery photos
- Removed the "Team" section/page (not relevant to a bakery)
- Kept the original layout, page structure, and styling approach

## Pages

- `index.html` — Home / landing page
- `gallery.html` — Product gallery ("Our Best Seller Products")
- `about.html` — About the bakery
- `contact.html` — Contact info and order form

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## Running the project

No build tools or dependencies needed — it's a static site.

1. Make sure the `css/`, `js/`, and `img/` folders sit alongside the HTML files.
2. Open `index.html` directly in a browser, or serve the folder locally for best results:
   ```bash
   python -m http.server 8000
   ```
   then visit `http://localhost:8000`.
